# ApexEdu Academy — 1-bosqich (ommaviy sayt)

## Ishga tushirish
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ papkasi (GitHub Pages uchun)
```

## Logo
`public/assets/logo.png` faylini o'zingizning logotipingiz bilan almashtiring. Fayl bo'lmasa, vaqtincha matnli nom ko'rinadi.

## Ma'lumotlar
Hozir vaqtincha ma'lumotlar `src/data/mock.ts` da. Komponentlar ma'lumotni `src/services/api.ts` orqali oladi,
2-bosqichda faqat shu qatlam Google Apps Script bilan almashtiriladi.
